# 후속 수정과 검증

[프로젝트](../README.md) / [전체 코드](CodeIndex.md)

아래 수정과 테스트는 포트폴리오 정리 과정에서 원본 프로젝트에 적용한 후속 작업입니다. 2025년 개발 당시 구현 및 검증 결과와 구분합니다. [출처 목록](SourceMap.md)에 기준 커밋과 후속 수정 파일을 표시했습니다.

## 변경한 동작

| 대상 | 변경과 확인할 함수 |
| --- | --- |
| 보급 위치 | `MapGeneratorComponent.TryGetSupplySpawnLocation`에서 반경 중복 배율을 제거하고 라디안과 안전 영역 중심으로 후보를 만듭니다. 최대 32회 안에 메시 범위와 여유 영역이 맵 및 안전 영역 안에 있고 점유와 충돌하지 않는 후보를 찾습니다. |
| 보급 실패 | bool 반환으로 위치와 실패를 구분합니다. 위치 탐색 실패 회차는 생략하고 Actor 생성 성공 후 점유 영역을 기록합니다. |
| 가림 집합 | `CompetitivePlayerCharacter.CheckObstaclesBetweenCamera`에서 현재 집합을 먼저 완성하고 진입 및 이탈 대상만 재질을 변경합니다. |
| 충돌 정보 | `MapGeneratorComponent.CalculateExtent`에서 BodySetup을 확인한 뒤 첫 Box에 접근하며 없으면 Bounds를 사용합니다. |
| 자원 반복문 | `ResourceGenerator.GenerateObjects`에서 반복 시작 시 시도 수를 증가시켜 잘못된 데이터와 탐색 실패도 횟수에 포함합니다. 목표 수의 3배 시도 후 부분 생성 결과를 기록합니다. |
| 일반 생성기 반복문 | 5단계 후속 수정에서 Obstacle, SubObstacle, Decoration과 Fence 생성기의 대체 위치 탐색 실패도 시도 횟수에 포함하도록 했습니다. 기존 배율과 생성 규칙은 유지합니다. |
| 점 위치 경계 | 5단계 후속 수정에서 비유한 좌표, 배열 초기화 상태, 실수 경계 및 반올림 이후 양 축 정수 경계를 확인한 뒤 인덱싱합니다. |

무작위 보급 후보 32회 실패는 유효 공간이 전혀 없다는 증명이 아닙니다. 보급 생략 정책이며 정상 배치를 반드시 찾아주는 탐색으로 설명하지 않습니다.

## 기존 회귀 테스트 결과

원본의 2026-09-06 실행 보고서를 확인했습니다. [요약 JSON](../Evidence/Stage2RegressionSummary.json)은 원본 결과 필드만 발췌하고 장치 식별값과 하드웨어 정보를 제외한 자료입니다. 이번 GitHub 정리 단계에서 새로 실행한 결과는 아닙니다.

| 테스트 | 확인 범위 | 원본 결과 |
| --- | --- | --- |
| MeshFallback | 메시 없음, BodySetup 없음, Box 없음, 정상 Box와 점유 셀 검사 | 성공 |
| SupplyMissingOwner | 소유 GameMode가 없으면 보급 탐색 실패, 출력 위치 유지 | 성공 |
| InvalidResourceData | 빈 목록, null 데이터, 메시 누락, World 부재, 전체 점유 경로의 반환 | 성공, 예상 경고 5개 |

[회귀 테스트 코드](../Source/Source/ShootingStar/Private/Tests/GenerationRegressionTests.cpp)와 [자원 반복 종료 로그 5줄](../Evidence/Stage2ResourceAttempts.log)을 함께 제공합니다. 성공 2개와 경고를 포함한 성공 1개, 실패 0개입니다. 자원 테스트의 점유 확인은 검사한 셀에 한정하며 맵 전체 상태의 완전한 검증으로 해석하지 않습니다. World 부재 실패는 실제 `SpawnActor` 내부 실패를 강제한 테스트가 아닙니다.

원본 Editor 빌드 통과는 2단계 작업 기록에 남아 있습니다. 위 테스트는 실제 보급 경계, 카메라 전환, 라운드 정상 재생성과 파일에 포함된 모든 게임 시스템을 검증하지 않습니다. 테스트 시작 시 기존 구조체 미초기화 필드 진단도 있었으므로 프로젝트 전체 오류가 없다는 의미는 아닙니다.

## 5단계 추가 수정 검증

일반 생성기 반복문과 점 위치 경계 수정 후 `ShootingStarEditor Win64 Development` 빌드 및 기존 3개와 신규 2개 회귀 테스트를 실행했습니다. [5단계 결과 JSON](../Evidence/Stage5RegressionSummary.json)은 성공 4개, 예상 경고를 포함한 성공 1개, 실패 0개입니다. 원본 보고서 시각 `2026.09.06-16.08.05`는 UTC이며 한국 시간으로 2026-09-07 01:08:05입니다.

| 신규 테스트 | 확인 범위 |
| --- | --- |
| GeneratorAttemptLimits | 전체 점유 맵에서 목표 2개를 지정하고 장애물, 주변 장애물, 장식은 6회, 펜스는 4회로 종료하는 로그를 각각 1회 기대합니다. 펜스는 장애물 후보 없음과 무작위 위치 실패 경로를 통과했습니다. |
| PointBoundary | 2499.49의 정상 셀, 2499.75의 상한 초과 반올림, 양 축 조합, -2500 포함과 -2500.1 제외, 정확한 상한 제외, NaN, 무한대, 미초기화 및 크기가 맞지 않는 배열, 정상 셀 점유를 확인합니다. |

[반복 종료 로그](../Evidence/Stage5GeneratorAttempts.log)의 4개 메시지는 테스트가 예상 경고로 등록해 런타임 로그에는 Verbose로 기록됐습니다. 기존 자원 실패 테스트의 예상 경고 5개는 경고 포함 성공으로 남아 있습니다. 테스트 프로세스에는 420초 제한을 적용했으며 제한 초과 없이 종료했습니다.

테스트 시작 전 기존 구조체 미초기화 필드 진단 6개는 계속 기록됩니다. 선택한 회귀 테스트 통과와 프로젝트 전체 진단을 구분하며, 정상 플레이와 보급 및 가림 시각 검증은 남아 있습니다. [2단계 코드 해시 목록](../Evidence/Stage2SourceManifest.json)을 보존해 과거 결과를 최신 코드 실행으로 혼동하지 않도록 했습니다.

## 남은 경계

- 외부 반복문의 종료와 개별 생성 성공은 구분합니다. 장식 군집 내부 처리와 펜스 패턴의 실제 인스턴스 수를 외부 반복문의 성공 횟수로 검증한 것은 아닙니다.
- 안전 영역 축소와 이동 중심, 맵 가장자리의 실제 보급, 가림 진입과 유지 및 해제, 라운드 전환 후 정상 자원 수는 플레이 검증이 남아 있습니다.
- 공간 검사의 첫 Box, 스케일 및 오프셋 제약은 [공간 검증 문서](SpatialGeneration.md)에 명시했습니다. 처리 시간, 프레임 개선과 메모리 절감의 신규 측정값은 제시하지 않습니다.
